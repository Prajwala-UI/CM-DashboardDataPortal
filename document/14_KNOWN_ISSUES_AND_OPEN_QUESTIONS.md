## 4. Differences from Angular (approved)

HashRouter kept; Bootstrap JS/jQuery removed (dropdown/collapse in React); forced reload replaced; dead code removed; logging off in prod; unknown routes redirect to login (Angular showed a navigation error); search inputs in login dropdowns do not autofocus; Font Awesome kit script not loaded; GET requests send an empty body so `Content-Type` is kept. Full list: [Angular docs 11 §3–5](../../document/11_ANGULAR_TO_REACT_MIGRATION_GUIDE.md).

## 5. Assumptions

1. The test API (`testapps.bbmpgov.in/CMDashboardAPI`) behaves like production apart from data.
2. The backend accepts the same payloads from React as from Angular (same browser, same headers).
3. Hash routing is acceptable for production URLs (as today).
